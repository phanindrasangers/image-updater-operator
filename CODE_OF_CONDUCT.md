# Community Code of Conduct

image-updater-operator follows the [CNCF Community Code of Conduct v1.3](https://github.com/cncf/foundation/blob/main/code-of-conduct.md), adapted from the Contributor Covenant.

## Reporting

Report unacceptable behavior to the project maintainers at [phanindra.sangers@gmail.com](mailto:phanindra.sangers@gmail.com). All reports will be reviewed and investigated promptly and fairly.

If a report involves a maintainer, or you are not comfortable reporting to the project directly, you may instead contact the [CNCF Code of Conduct Committee](https://github.com/cncf/foundation/blob/main/code-of-conduct.md#reporting).
